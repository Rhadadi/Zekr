# Study Quran commentary recordings

The owner requested publication of these existing ElevenLabs recordings on October 16, 2026. They contain the English commentary for Surah Yasin (74 notes) and Surah Yusuf (89 notes), narrated by George using eleven_v4_turbo. The 163 notes cover 194 ayahs; passages shared by several ayahs play once.

These recordings read the original commentary, including its references. They are AI generated. The Google listening-edition samples are separate experiments and are not part of this publication.

Each manifest contains exact source-text hashes, ayah links, MP3 checksums and durations. `tools/study_audio.py` validates them against the separately published Study Quran database before installing the files into the web or iPhone build. No API credentials, generation cache or source PDF belongs here.
